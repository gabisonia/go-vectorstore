Binary source: `b38b1eafd7b181a3fcea5e61a1764e9af38fd235` (modified tree: False). Dependencies: `modernc.org/libc v1.75.7`, `modernc.org/sqlite v1.59.0`.

Raw complete matrix: [random.jsonl](random.jsonl). 4 fixtures, 288 timed, independently verified pages.

Run window: `2026-11-17T22:05:32.084689Z` to `2026-11-17T22:33:51.147017Z`.

Body: 4096 bytes; batch: 256 records; metric: L1. Warm values are medians of 3 calls. Reopened values are one first-query observation plus separately measured open time.

Canonical uses an unprojected database; packed Go/native share a second file with identical canonical data. Mode order rotates. Generation, validation and requested GC are outside query timers. OS caches are untouched: reopened does not mean cold disk I/O.

Three warm samples do not establish tail latency. This is one machine, one corpus seed and one pass; neighboring Go GC/scavenging and OS work can affect results. CSV summaries retain minima/maxima and raw JSONL retains every sample/outlier. Go allocation counters are not RSS or SQLite temporary-storage usage.

Cases follow the configured top order (10 before 100 in the published matrix). Cache, storage and runtime history carry between cases; nonmonotonic timings do not establish that a larger requested page is intrinsically faster.

## Write-plan defect discovered during measurement

Diagnostic source `96cdace22192d2e961c3631858f00836a607fc4e`: [diagnostic-before-partial.jsonl](diagnostic-before-partial.jsonl). Completion marker present: False. The run was deliberately interrupted during a later load; only its 2 fully emitted fixture records are diagnostic evidence. This file is excluded from the final matrix above.

EXPLAIN selected a collection-only primary-key scan for per-record projection cleanup. The CPU profile was dominated by reads from that cleanup. Requiring the existing collection/key index removes the repeated collection scan without changing storage layout or canonical semantics. ## Interpretation

Packed/native paths reduce full-payload decoding for unfiltered dense searches. Filtered searches keep canonical scan cost. Projections add storage and write work; native candidates use SQLite temporary storage and complete ties can eliminate candidate reduction. Choose settings using representative local workloads and longer isolated runs; this matrix establishes neither capacity limits nor tail latency, RSS, cold-disk behavior or concurrent-service throughput.
